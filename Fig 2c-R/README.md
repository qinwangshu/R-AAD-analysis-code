# Figure 2c

## Code and data

| File | Description |
|---|---|
| `Fig2c_plot.R` | R code for Figure 2c. |
| `Fig2c_all_pathways.csv` | Input data. Pathway names, comparisons, hit counts and enrichment P values. |
| `Fig2c_plot_data.csv` | Selected plotting data; regenerated by the script. |
| `Fig2c_22pathways_AI_text.svg` | Reference figure. |

## Requirements

R 4.6.1; no additional R packages are required. SVG/PNG export requires Cairo support: `capabilities("cairo")` must return `TRUE`.

## Run

Keep the R script and input CSV together. Open a terminal in this folder and run:

```text
Rscript --vanilla Fig2c_plot.R
```

Alternatively, set the R/RStudio working directory to this folder and run:

```r
source("Fig2c_plot.R", encoding = "UTF-8")
```
