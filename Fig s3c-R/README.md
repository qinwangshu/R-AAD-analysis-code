# Figure S3c

## Code and data

| File | Description |
|---|---|
| `FigS3c_plot.R` | R code for Figure S3c. |
| `FigS3c_data.csv` | Input data. Feature annotations and abundances for 81 features across 152 samples. |
| `FigS3c_editable.svg` | Reference figure. |
| `FigS3c_results.csv` | Clustering results; regenerated by the script. |

## Requirements

R 4.6.1, Mfuzz 2.72.0 and its dependencies (including e1071 and Biobase). Install in R:

```r
install.packages("BiocManager")
BiocManager::install("Mfuzz", ask = FALSE, update = FALSE)
```

## Run

Keep the R script and input CSV together. Open a terminal in this folder and run:

```text
Rscript --vanilla FigS3c_plot.R
```

Alternatively, set the R/RStudio working directory to this folder and run:

```r
source("FigS3c_plot.R", encoding = "UTF-8")
```

## Outputs

- `FigS3c_editable.svg`
- `FigS3c_results.csv`

Outputs are saved beside the input CSV. Existing outputs with the same names are overwritten.
