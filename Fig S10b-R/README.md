# Figure 4b | Validation cohort

Keep `plot_roc.R`, `ROC_coordinates.csv` and `ROC_summary.csv` together. The script uses base R.

Open a terminal in this folder and run:

```text
Rscript --vanilla plot_roc.R
```

In RStudio, open `plot_roc.R` and click **Source**.

The finished figure `Fig4b_Covariate_Adjusted_ROC.svg` is included. Running the script regenerates it in the same folder.
